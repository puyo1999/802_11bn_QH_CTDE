# 무작위 토폴로지 실험 계획

- 상태: **계획 초안** (Rayleigh 페이딩 부분 재실험 완료 후 확정)
- 작성일: 2026-10-26
- 관련 문서: `paper/README.md`, `experiments/oracle_gap.py`

## 1. 목적

현재 논문의 결론은 고정 토폴로지 6개(T1–T6)에서 나왔다.

- 협조 이득(정확 oracle 대비 Co-TDMA 손실)은 저부하(λ ≤ 2)에서 1% 미만이고, 고부하에서만 커진다.
- 학습 스케줄러의 손실에서 MCS 선택(link adaptation) 몫이 가장 크고, AP 간 정보 몫은 작다(최대 약 9%p).
- 이상적 MCS를 주면 학습자가 Co-TDMA를 넘는 경우는 협조 이득이 가장 큰 두 경우뿐이다.

고정 토폴로지 6개만으로는 "골라 쓴 사례에만 맞는 결론"이라는 지적을 피하기 어렵다.
무작위 토폴로지 실험의 목적은 두 가지다.

1. **일반화**: 위 결론이 토폴로지 분포 전반에서 성립하는지 확인한다.
2. **조건 규명**: 어떤 기하 조건에서 협조 이득과 학습 손실이 커지는지 보인다.

## 2. 설계 원칙: 공간 크기가 아니라 기하 비율

SINR은 `서빙 신호 / (간섭 + 잡음)`이고 경로손실은 거리의 3제곱에 반비례한다.

- **간섭 지배 구간**에서는 SINR이 거리의 **비율**로만 정해진다. 같은 배치를 통째로 키워도 결과가 거의 같으므로,
  밀도가 비슷한 배치를 넓은 공간에 펼치는 것은 같은 실험의 반복이다.
- **잡음이 무시되지 않는 구간**에서는 절대 거리도 영향을 준다. 현재 모델(송신 15 dBm, 잡음 −95 dBm)에서
  서빙 거리 10 m의 SNR은 약 33 dB, 20 m는 약 24 dB이며, 최고 MCS 임계값(24.5 dB)이 20 m 부근에서 걸린다.

따라서 기존 생성기(`src/envs/topology.py::random_topology`, 60×40 m 공간에 AP 4개를 무작위로 배치)처럼
공간 하나에 흩뿌리지 않고, **결과를 좌우하는 변수를 직접 표본화**한다.

## 3. 설계 변수

| 변수 | 의미 | 범위 (초안) |
|---|---|---|
| AP 간 최소 거리 `d` | 밀도, 간섭 세기 | 10–40 m |
| STA 서빙 거리 비율 `r/d` | 셀 가장자리 정도 (SIR) | 0.1–0.5 |
| AP 수 `N` | 협조 대상 규모 | 3–6 |
| 중첩 STA 비율 | 중첩(overlap) 제약의 영향 | 0–30% |
| AP당 STA 수 | 스케줄링 선택지 | 1–3 |

- 절대 거리 범위(10–40 m)는 잡음 제한이 생기는 구간을 포함하도록 잡았다.
- `N ≤ 6`이면 정확 oracle의 전수 탐색이 감당 가능하다(AP당 선택지 3개일 때 3⁶ = 729가지).
- 표본화는 라틴 하이퍼큐브(또는 층화 표본)로 5차원 공간을 고르게 덮는다.

## 4. 실험 구성

| 단계 | 토폴로지 수 | 조건 | 예상 시간 (4코어) | 얻는 것 |
|---|---|---|---|---|
| 1단계: 기준 정책 | 100–200 | λ ∈ {1, 5, 8}, 시드 3 | 수 분 | 협조 이득의 분포, 변수별 영향 |
| 2단계: 학습자 | 20 | λ ∈ {5, 8}, 토폴로지당 시드 1 | 약 7시간 (30개면 약 11시간) | 손실 분해 결론의 일반화 |

- **1단계**: 고정 토폴로지 6개 × 부하 7개 × 시드 3개 스윕이 약 24초 걸렸으므로 100–200개도 수 분이면 된다.
  협조 이득을 히스토그램/누적분포와 변수별 산점도(또는 회귀)로 보인다.
- **2단계**: 지금까지 학습자 손실 분해 값은 토폴로지마다 약 5–10%p 흔들렸으므로, 20개면 평균의 표준오차가
  약 2%p다. 같은 토폴로지에서 MAPPO와 Central PPO를 짝지어 비교(쌍별 검정)할 수 있다.
  시드보다 토폴로지 수를 늘리는 쪽이 일반화 근거로 강하다.
- 학습자 변형: MAPPO / Central PPO × MCS {학습, 이상적(genie)}. ARF는 고정 토폴로지에서 효과가
  토폴로지마다 들쭉날쭉(−12 ~ +14%p)으로 결론이 났으므로 제외를 기본으로 한다(확정 시 재검토).
- 비용 근거: 1000 에피소드 학습 1회에 MAPPO 약 7.5분, Central PPO 약 14분(작업자 1개 기준).

## 5. 채널 모델

Rayleigh 페이딩 부분 재실험(λ ∈ {5, 8} × T3, T6 × 시드 3, `experiments/oracle_gap_results_envv2_fading/`)
결과에 따라 정한다.

- 결론이 페이딩 유무와 무관하면: 결정적 경로손실 모델 하나로 진행한다.
- 결론이 달라지면: 1단계는 두 모델 모두, 2단계는 결론이 갈린 모델 기준으로 진행한다.

참고로 기준 정책 스윕(페이딩 포함)에서는 λ ≤ 2의 결론이 유지되고, 고부하에서 협조 이득이 커졌다
(예: λ = 5, T6에서 10% → 21%).

### 모델링하지 않는 채널 요소와 근거

| 요소 | 판단 | 근거 |
|---|---|---|
| 도플러(시간 상관) | 범위 밖 | 6 GHz, 보행 속도 1 m/s에서 도플러 주파수 약 20 Hz, 코히런스 시간 약 20 ms로 슬롯(1 ms)보다 길다. 결정적 모델(변화 없음)과 슬롯별 독립 페이딩(매 슬롯 변화)이 실제 채널을 양쪽에서 감싼다. |
| 섀도잉 | 범위 밖 | 한 에피소드(200 ms) 동안 거의 고정이며, STA 위치를 바꾼 효과와 같아 토폴로지 다양성으로 대신한다. |
| 이동성 | 범위 밖 | 수 초 이상의 연결(association)·토폴로지 변화 문제로, 에피소드 단위 스케줄링 결정의 범위를 벗어난다. |

리뷰에서 요구하면 도플러는 가우스-마르코프 모델로 추가하고 핵심 조건만 부분 재실험한다.

## 6. 구현 작업

1. **생성기 보완** (`src/envs/topology.py` 또는 새 모듈)
   - 설계 변수 `(d, r/d, N, 중첩 비율, AP당 STA 수)`를 입력으로 받는다.
   - AP는 최소 거리 `d`를 지키도록 배치한다.
   - 중첩 STA는 AP 사이 경계 부근에 두고 `overlap_with`를 기록한다. 기존 생성기는 중첩 STA를 만들지 않는다.
2. **재현성**
   - 생성 시드를 고정하고, 생성한 토폴로지를 `configs/topologies_random.yaml`로 저장해 커밋한다.
   - 각 토폴로지에 설계 변수 값을 메타데이터로 남긴다.
3. **실험 스크립트**
   - `experiments/oracle_gap.py`가 토폴로지 파일을 인자로 받도록 확장한다(`--topology-file`, `--topos all`).
   - 작업 단위 JSON 저장과 이어서 실행(resume)은 기존 기능을 그대로 쓴다.
4. **테스트**
   - 생성기: 최소 거리 제약, 중첩 STA 표시, 시드 재현성.
   - 정확 oracle 전수 탐색: `N = 6`에서 실행 시간 확인.

## 7. 결과물과 논문 반영

- 그림: 협조 이득 분포(누적분포), 설계 변수별 협조 이득 산점도.
- 표: 무작위 토폴로지 20개에서 손실 분해(링크 적응 / 정보 / 최적화 손실) 평균 ± 표준편차, 신뢰구간.
- 본문: 실험 설정에 생성 절차와 설계 변수를, 결과에 일반화 절을, 한계에 범위 밖 채널 요소를 추가한다.
